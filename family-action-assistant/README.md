# 家事有着落

实验 02：家庭小管家。

核心体验：把家庭待办、记账和提醒放在一个轻量工具里。输入一句自然语言，整理成家庭事项、日期、提醒、参与人和准备清单；需要时快速记下一笔支出。

## MVP 能力

- 育儿、家庭、购物事项自动分类
- 宝宝体检、疫苗接种、带娃出门、购物清单快捷模板
- 识别今天、明天、后天、周几和年月日
- 识别“提前一天提醒”等提醒表达
- 提取人物和“带/准备/记得”清单
- 结果页可编辑标题、类别、负责人、日期、时间、提醒和清单
- 首页按今天、未来 7 天、待安排时间分组
- 本机保存、完成、删除
- 导出 `.ics` 加入手机日历
- 原生分享或复制事项给家人
- 首页显示未完成待办和本月家庭支出概览
- 本地家庭记账：金额、日期、类别、支付人和备注
- 查看最近 5 笔支出，支持删除
- 记账支持自然语言识别金额、日期、类别和支付人
- 待办时间支持常用时间快捷选择，也可切换自定义时间
- 首页输入会自动判断是待办还是记账；一句话包含多件事时，会逐项确认并分别保存
- 首页支持浏览器语音输入（需浏览器支持语音识别并授权麦克风）

当前版本不连接后端、不上传数据，也不做医疗诊断。
