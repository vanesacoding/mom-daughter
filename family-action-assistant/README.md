# 家事有着落

实验 02：家庭 AI 行动助手。

核心体验：输入一句自然语言，整理成家庭事项、日期、提醒、参与人和准备清单。

## MVP 能力

- 育儿、家庭、购物事项自动分类
- 宝宝体检、疫苗接种、带娃出门、购物清单快捷模板
- 识别今天、明天、后天、周几和年月日
- 识别“提前一天提醒”等提醒表达
- 提取人物和“带/准备/记得”清单
- 结果页可编辑标题、类别、负责人、日期、时间、提醒和清单
- 首页按今天、未来 7 天、待安排时间分组
- 本机保存、完成、删除
- 导出 `.ics` 加入手机日历
- 原生分享或复制事项给家人

当前版本不连接后端、不上传数据，也不做医疗诊断。
